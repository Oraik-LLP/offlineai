# Design reference synthesis

## Sources

- Fintra website by Taras Migulko for Emote Agency
- Blockchain Wallet Landing Page by Bogdan Falin for QClay
- Resurrect X product, security, and design specifications

## What the implementation borrows

### Fintra

- Large, confident hero message
- Light, high-clarity public entry surface
- Buoyant product composition and spring-like hover feedback
- Product interface shown early
- Compact benefit blocks and clear trust signals

### Blockchain wallet reference

- Restrained dark secondary-page system
- Simpler sans-serif reading typography
- Clear security hierarchy
- Strong contrast and minimal navigation
- Modular product and capability explanations

## Resurrect X interpretation

The public home page combines legal-broadsheet typography with Fintra-like buoyancy. Security and Architecture use the dark, simpler system. The authenticated workspace remains compact and operational. Motion communicates hierarchy, focus, or state and respects reduced-motion preferences.

The references guide composition and behavior only. No layouts, copy, brand assets, or illustrations are copied.
